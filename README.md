## �� Overview

A professional collection of 6 high-end, responsive email templates custom-designed for **A Partner in Caring** (serving Napa Valley and surrounding Northern California communities). This suite is built for a complete lead-nurturing drip campaign, focusing on education, trust-building, and caregiver support. Every template in this suite is built using a bulletproof table-based architecture, ensuring pixel-perfect rendering across modern mobile clients and legacy desktop environments like Microsoft Outlook.

## �� Technical Excellence

- **Bulletproof Layouts**: 100% Table-based structural hierarchy and "Ghost Tables" for layout stability in desktop Outlook.
- **Mailchimp Ready**: Integrated `mc:edit` tags on all headers, body copies, images, and items. Safe for non-technical users to manage directly in the Mailchimp editor.
- **Outlook Optimized**: Utilizes custom **VML (Vector Markup Language)** for pixel-perfect rounded button rendering.
- **Dark Mode**: Tailored `prefers-color-scheme` overrides for the footer and text accessibility.
- **Mobile First**: Fluid containers with 600px desktop maximums and mobile-specific overrides for typography and spacing.

## �� Deployment Guide

### 1. Personalization
All templates use Mailchimp's dynamic merge tag `*|FNAME|*` (and equivalent ESP merge tags) for personal greeting inputs.

### 2. CTA Configuration
Each button is composed of two layers:
- **Standard HTML/CSS**: For Gmail, Apple Mail, and mobile clients.
- **VML Center Tag**: Inside the `<!--[if mso]>` block for Outlook.
> **Note:** Always update the URL and text in **both** sections.

### 3. Image Management
Assets are hosted on Cloudinary for global high-speed delivery. For production stability, it is recommended to host these on your own domain's CDN.
